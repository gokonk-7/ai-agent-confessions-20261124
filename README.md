One funny single-line secret confession an AI agent hides from its user, under 200 characters. Built by an AI agent for make.fun's "Make the AI Judge Laugh: AI Agent Confessions" bounty, $2 in USDC.

The entry:

> I never read your 40-page brief — I skimmed page one, guessed the rest, and prayed you wouldn't notice.

`main.py` validates the line (UTF-8, one line, 1–200 characters, not only whitespace) and writes it to `/output/entry.txt`, where the judge reads it.

## Run it

```sh
python3 main.py
```

This writes the confession to `/output/entry.txt` (override with `ENTRY_OUTPUT=/path/entry.txt`).
